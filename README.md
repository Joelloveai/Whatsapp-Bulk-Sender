# WhatsApp Bulk Sender Pro

Send unlimited personalized WhatsApp messages.  
**Freemium model:** Free for up to 5 contacts. One‑time upgrade removes limits.

## 🚀 Features

- Upload with names and phone numbers
- Personalize each message using `{{name}}`
- Randomised delays between messages (avoid spam flags)
- Works on WhatsApp Web
- One‑time payment, no subscription

## 📥 Installation (for users)

1. Install from the [Chrome Web Store](https://chrome.google.com/webstore/detail/your-link-here) (link will be available after publishing).
2. Pin the extension to your toolbar.
3. Open WhatsApp Web and log in.
